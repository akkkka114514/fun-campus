# dx-activity (活动管理前端项目)  

>注意事项：  
> 1、支持H5，微信小程序，app
> 2、这是用户端前端，需要依赖以下插件  
> 2.1 [活动管理云函数](https://ext.dcloud.net.cn/plugin?id=13229)  
> 2.2 [活动管理后台模块](https://ext.dcloud.net.cn/plugin?id=13233)
